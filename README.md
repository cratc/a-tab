# a-tab

一个基于 OneNav 网址数据、设计的高度可自定义书签导航页 WordPress 插件。

## 功能特性

- 🎨 **风格界面** - 玻璃拟态设计，支持自定义壁纸
- 📁 **文件夹分组** - 支持 2×2 大文件夹，内部图标与外部一致
- 📝 **备忘录组件** - 便签夹式备忘录，支持多便签、实时保存、主题色切换
- 🔍 **快速搜索** - 实时搜索书签
- 📱 **响应式设计** - 完美适配桌面和移动端
- 🌙 **暗色模式** - 自动适配系统主题
- 🎯 **拖拽排序** - 自由拖拽调整书签位置
- 📦 **多数据源** - 支持 OneNav 主题数据和独立模式

## 安装

1. 下载插件 zip 包或克隆仓库到 WordPress 插件目录：
   ```bash
   cd wp-content/plugins/
   git clone https://github.com/cratc/a-tab.git
   ```

2. 在 WordPress 后台启用插件

3. 新建页面，选择模板 **"书签导航页"**

4. 访问该页面即可看到导航页

## 配置

### 后台设置

进入 WordPress 后台 → **a-tab** 菜单：

- **通用设置** - 数据源选择、链接健康检查
- **商店分类** - 选择要在商店中展示的分类

### 前端设置

在导航页右键点击空白处：

- **添加标签** - 添加新书签
- **添加备忘录** - 添加便签夹组件
- **新文件夹** - 创建文件夹分组
- **更换壁纸** - 切换背景壁纸
- **设置** - 打开设置面板

### 书签操作

右键点击书签卡片：

- **新标签打开** - 在新标签页打开链接
- **编辑标签** - 修改书签信息
- **移动至分类** - 移动到其他分组
- **布局** - 切换卡片大小（1×1、1×2、2×2、2×4）
- **删除标签** - 删除书签

## 备忘录组件

点击备忘录卡片打开便签夹界面：

- 左侧：便签列表 + 搜索
- 右侧：标题 + 内容编辑区
- 底部：新建按钮 + 删除按钮
- 点击颜色圆点切换主题色
- 输入内容后自动保存（400ms 防抖）

## 文件夹

- 文件夹显示为 2×2 大卡片
- 内部 4 个图标大小与外部书签一致
- 点击打开文件夹展开弹框
- 拖拽书签到文件夹可移入

## 技术栈

- PHP 7.4+
- WordPress 5.0+
- Vanilla JavaScript (无框架)
- CSS Grid + Flexbox
- localStorage (本地数据)

## 数据库

插件会创建以下数据表：

- `bm_nav_pages` - 导航页配置
- `bm_nav_groups` - 分组信息
- `bm_nav_items` - 书签项目
- `bm_card_components` - 卡片组件（预留）

## REST API

插件提供以下 REST API 端点：

- `GET /wp-json/bm/v1/bookmarks` - 书签列表
- `GET /wp-json/bm/v1/categories` - 分类列表
- `GET /wp-json/bm/v1/search?q=关键词` - 搜索书签
- `POST /wp-json/bm/v1/nav-items` - 创建书签
- `PUT /wp-json/bm/v1/nav-items/{id}` - 更新书签
- `DELETE /wp-json/bm/v1/nav-items/{id}` - 删除书签

## 兼容性

- **OneNav 主题** - 自动检测并使用 OneNav 数据
- **独立模式** - 无需 OneNav，使用内置数据管理
